# 从设备时钟分解最坏工期增量

沿用[固定排列的精确模型](../flowshop_monge_budget/RELEASE_DATES.md)。对可行锁集合 $S$，令 $C(S)$ 为其最早工期，目标是 $\Delta^*=\max_S[C(S)-C(\varnothing)]$。加工、换型和到达时间均为整数，选择成本为正整数。提前换型可以在作业到达之前开始，但须服从设备可用时刻。以下近似精度以新增工期计量。

## 分解与误差证书

给定锁集合，各机开放或连续运行的递推均由取最大和加常数构成。把首机作业到达向量视作一个外部来源，把每台设备的可用时刻各视作一个外部来源。逐一保留一个来源，其余绝对来源取负无穷。按递推分配最大值，有 $C(S)=\max_h C_h(S)$。设备来源在设备 $h$ 产生同一个向量 $R_h+P_h$，与该设备是否锁定无关，因此该来源只受后续设备的锁定影响。任意来源后保留原有强制锁。写 $g_h(S)=C_h(S)-C_h(\varnothing)$、$\delta_h=C(\varnothing)-C_h(\varnothing)$。于是

$$\Delta^*=\max_h[P_h^*-\delta_h],\qquad P_h^*=\max_{S\text{ 可行}}g_h(S).$$

每个来源的齐次检查点图可用[共同的段权](../flowshop_monge_budget/PROOF.md)。设 $q_h(j)$ 为只遵守强制锁时将 $j$ 作为下一个检查点的最早启动时刻。将段权 $a(i,j)$ 改成 $q_h(i)+a(i,j)-q_h(j)$。该差非负，因为加入检查点 $i$ 不会使下游更早。对一条可行路径求和时，势函数项相消，正好得到该来源相对自身基准的新增工期。

只保留端点成本之和不超过预算的边。每条保留边都可用其两个端点和原有强制锁组成一条可行路径，且其他边收益非负。设保留边最大收益为 $M_h$，该来源路径最长为 $\ell_h$ 条边，有 $M_h\le P_h^*\le \ell_h M_h$。若 $M_h=0$，直接判定该来源无增量。否则用 $u_h=\eta M_h/\ell_h$ 向下取整边收益，并按检查点和整数化收益记录最小所需费用。每条路径至多损失 $\eta M_h$。回溯锁集合后用原模型得到可行下界 $L$。每个来源的最优整数化收益加 $\ell_h$ 个单位得到该来源上界，再扣 $\delta_h$，取最大得到 $U$。实现也用锁定所有单独可负担设备所得的工期上界剪枝。

所得证书满足 $L\le\Delta^*\le U$ 及 $L\ge\Delta^*-\eta P_h^*$，对任何达到最大值的来源 $h$ 成立。为保证相对误差，若已知某个最优来源的 $\delta_h\le\rho\Delta^*$，取 $\eta=\varepsilon/(1+\rho)$ 即给出 $L\ge(1-\varepsilon)\Delta^*$。当设备绝对约束在所有锁集合上均冗余时，只需作业到达来源，$\rho=0$，可得到 FPTAS。一般情形通过 $L\ge(1-\varepsilon)U$ 检查某次运行是否已经达到目标精度。未经额外限制，无法根据最优来源的事后余量保证自适应缩放的运行时间。

共有 $O(m)$ 个来源。每个来源的收益状态数至多 $O(m^2/\eta)$，最多扫描 $O(m^2)$ 条边，直接实现为 $O(m^2n+m^5/\eta)$ 次算术运算。预算只进入费用比较。因设备可用时刻能使正性判断成为 NP 完全，一般情形的区间可能同时包含零和正整数。上述条件近似保证与不可能性相容。

## 独立验算

`python -B validate.py --output /tmp/flowshop_release_approx_replay.json` 使用另一套逐作业时钟实现核对 200 个随机小实例的 3,933 个可行锁集合、400 个上下界证书，以及 115 个正最优值例的条件相对保证。85 个零最优值例各检查两种精度。六个计时矩阵含三份曾使用的公开 Ruíz 工时前缀以及三份新合成工时，机器可用、换型、到达和费用全部合成。精度参数 $1/4$ 时，六个下界恰等于精确最优，上界证明其中两个。精确法在这批小预算案例用 0.66 至 7.18 CPU 毫秒，近似实现用 1.06 至 8.99 CPU 毫秒。

在另一个受控例中，无掩盖时最大增量为 436。逐步增加末机时钟所设阈值，精确增量依次为 436、219、1、0。精度参数保持 $1/4$ 时，区间依次为 $[430,509]$、$[213,292]$、$[0,74]$、$[0,73]$，末两例无法区分。完整参数、见证和单例计时见[验证结果](results.json)。
