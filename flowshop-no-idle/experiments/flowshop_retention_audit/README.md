# 最少时钟保留的独立复核

Proposition 7 的一对二基数间隙成立。独立种子生成的 112 个背包实例中，60 个最优只需一个时钟，52 个最优需两个。逐工序核对了机器日期和首工序到料日期两种编码、2,452 个预算可行锁场景及 1,984 个空集或单时钟保留选择。 [原始结果](results.json) · [复跑脚本](audit_retention.py) · [命题及上下文](../flowshop_manuscript/manuscript.md)

## 间隙和复杂度

对于可选项集合 \(S\)，令 \(v(S)\) 为选中利润之和。两作业构造在全版中的末工期为 \(\max\{H,C_0+K+v(S)\}\)，其中 \(K=1+\sum_i v_i\) 且 \(H=C_0+K+T-1\)。只保留末钟时，其他项最多产生 \(C_0+\sum_i v_i < H\)，所有可行方案的末工期均为 \(H\)。如果 \(T\ge2\)，空锁集合的全版工期为 \(H>C_0+K\)。去掉末钟后，即使保留其余时钟也只能达到 \(C_0+K\)，因此末钟必留。所有其他局部日期为零，且每行首工序的上游到达非负，零日期冗余。末钟单留就足够，当且仅当所有预算可行的 \(S\) 满足 \(v(S)<T\)。

倍增利润和目标可在保留背包判定的同时保证 \(T\ge2\)，且增加的二进制长度为常数。\(T=1\) 确实可以破坏间隙。单个费用为 1、利润为 2 的项在预算 1 下，全版与只保留首钟的工期均为 \((9,11)\)，末钟单留为 \((9,9)\)。这时背包能达目标，最优仍只需一个时钟。 [边界夹具](results.json)

该限定判定属于 coNP。对空保留集合和最多 \(m\) 个单时钟候选，各提供一个预算可行锁集的误差见证，逐一验证工期及预算。反背包归约给出 coNP 困难性；最多 \(m+1\) 次伪多项式分离可判定全部候选，支持弱 coNP 完全分类。这个成员资格证明依赖保留上限为固定常数。当保留上限作为输入时，直接的量词结构为 \(\exists\) 保留集合、\(\forall\) 可行锁情景，只凭此证明得到 \(\Sigma_2^P\) 的上界。

对最小化问题，严格小于二的乘法近似须返回可行解。最优为 1 时，整数基数结果只能是 1；最优为 2 时，任何可行结果至少为 2。因此该算法能区分两个背包分支。在此仅有两个非冗余时钟的子类中，线性时间先检验删去全部时钟是否达到容差，如果可行就保留空集，否则保留两钟。这给出二近似，并处理最优为零的分支。对任何固定整数容差 \(\varepsilon\ge0\)，把构造的时长和日期乘 \(\varepsilon+1\)，即能把每个原先的正整数误差保留在容差外。独立夹具取容差 5，缩放 6 倍后仍得到一与二的间隙。 [正容差夹具](results.json)

## 反向影响和约束生成

给出一行各完工位置的终点权重 \(w_t\)。开放行的输入位置 \(u\) 可以影响全部 \(t\ge u\) 的输出，因此权重为 \(\max_{t\ge u}\{w_t+P(t)\}\)。锁定行让每个输入位置覆盖全行，改用全行最大值。每行末作业的权重始终有限，且属于每个开放后缀，因此代码可以把不可达的后缀项替换为该末作业项。把权重应用到局部时钟向量可得该源在末机的贡献；减去上游偏移得到传给前一机的入流权重。独立验证直接模拟了 591 个锁情景的 3,291 个入口或局部源贡献，全部逐项吻合。

删钟见证产生的支持集恰是该情景中贡献至少达到 \(C(S)-\varepsilon\) 的时钟。入口和任何保护时钟一旦达到此阈值，该情景就无法违反当前保留集合。真正的违反切必非空，并与当前保留及保护集合不交。当前集合满足所有旧切，因而新切无法等于或包含任一旧切。累积切提供下界，分离通过提供可行上界。精确主问题的分支覆盖当前首条未满足的切；一批两两不交的未满足切，各至少需要一个不同的新增时钟，因此是合法的下界。独立逐工序枚举覆盖 84 个一般模型的 193 个保留查询，包含 152 个正容差查询、94 个保护时钟查询和 75 个存在零费附加锁的查询。还复核了四个候选时钟上允许的全部 32,768 个超图，即只含非空切的全部切族，主问题基数全部匹配。

低层 `minimum_hitting_set` 接受空切族，返回空保留集。若直接传入包含空切的主问题，它会在贪心选点时引发 `IndexError`。当前约束生成器显式阻止这种输入，所以该接口边界不影响所审命题与运行路径。

## 复验

脚本使用独立的开始时间约束模拟。它只调用主实现来获取待验证的反向贡献、保留证书和分支定界结果，然后按锁集合及保留集合枚举比对。输出锁定了运行所读的源码摘要。两次复跑均使用逻辑 CPU 0，原次约用 1.38 CPU 秒。主实现和论文稿未在本审计中改动。

```bash
taskset -c 0 /usr/bin/python3 -B experiments/flowshop_retention_audit/audit_retention.py --output /tmp/flowshop-retention-audit-replay.json
cmp experiments/flowshop_retention_audit/results.json /tmp/flowshop-retention-audit-replay.json
```
