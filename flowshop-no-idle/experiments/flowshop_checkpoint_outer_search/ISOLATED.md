# CPU 28 独立复验

同一预锁协议的六矩阵、两档锁预算和两档时间全部复跑。只换执行入口的 CPU 绑定，原搜索函数、工时哈希、起点、种子和固定提案轨迹均与原跑一致。在逻辑 CPU 28、物理核 14 上运行，Antigravity 的已知固定工作核和另一组复验位于其他核心。原共享核结果单独保留。 [原跑](results.json) · [新原始结果](isolated_cpu28.json) · [复验入口](replay_isolated.py)

## 整体门槛

合并预定两档锁预算，每个时间窗有 12 个配对。两档时间、两种比较的整体平均最坏工期改进均低于 1%。公开组与独立合成组的整体方向均正。检查点臂在全部 24 个配对中完成更多提案。

| ---: | ---: | ---: | ---: | ---: | ---: |
| 0.15 秒 | 0.239% | 5/7/0 | 0.490% | 7/1/4 | 737 / 427.5 / 293.5 |
| 0.45 秒 | 0.109% | 8/4/0 | 0.160% | 9/1/2 | 2,105.5 / 1,575.5 / 979.5 |

作为原共享核结果的核对，三锁 0.45 秒的自适应比较由 1.075% 降至 0.586%。隔离复验的主结论是更高的搜索吞吐与小幅工期改善。固定 48 提案的 12 条配对轨迹全等，累计 CPU 加速 1.441 倍。独立末态复算 5,971 次均一致。复验共消耗 30.205 秒进程 CPU，包括初始化及核验，任一搜索臂的最大截止超限为 1.840 毫秒。
