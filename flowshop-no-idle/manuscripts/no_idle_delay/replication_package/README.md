# Referee Replication Package

Companion replication archive for:
**"A single availability date changes the approximability of delay in fixed-order flow shops"**

## Requirements
- Python 3.10+ (standard library only; zero third-party packages or commercial solvers required).

## Contents
- `flowshop_core.py`: Self-contained exact reference implementations of all algorithms in the main manuscript and Technical Appendix:
  - Direct physical operation-level simulator (`simulate_schedule`, supporting both Section 2 and Appendix A operation-level timing).
  - $O(m^2 n)$ machine-index checkpoint graph (`build_checkpoint_graph`, Lemmas 1–2).
  - Exact plain machine-index DP (`solve_exact_plain`) and anti-Monge binary-search upper-envelope DP (`solve_exact_envelope`, Theorem 1).
  - $O(mn)$ backward max-plus transpose and singleton positive-increase detector (`corollary1_singleton_check`, Corollary 1).
  - Source-wise certified approximation with exact rational scaling (`solve_source_approx`, Theorem 3 & Corollary 2).
  - $O(mn)$ downstream suffix deletion maximum-error test (`suffix_deletion_max_error`, Theorem 5).
  - $O(mn)$ all-completions minimum-cardinality local support (`min_all_completions_support`, Proposition A.1).
  - Uniform-threshold anti-Monge deletion oracle (`deletion_threshold_oracle`, `arbitrary_deletion_max_error`, Appendix B / Theorem 6).
  - Exact constraint-generation minimum clock retention (`minimum_retained_clocks`, Appendix B / Proposition 7).
- `maxplus_cascades.py`: Reference implementation for Appendices E and F:
  - General feedforward switched max-plus cascade simulator and projective diameter $D(K)$ (`projective_diameter`, Proposition E.1).
  - $O(N)$ linear-time singleton error sweeps (`linear_singleton_errors`).
  - Nonconsecutive clock deletion error certificates (`nonconsecutive_deletion_certificate`, Proposition F.1) with exact one-dimensional Handler–Zang convex chord search for the Lagrangian dual bound.
- `verify_all.py`: Single-command end-to-end verification suite checking every theorem, corollary, proposition (including Corollary 2 and Appendices E–F), boundary counterexample, degenerate edge case (including $m=1$, $n=1$, $B=0$, and 128-bit binary budgets), and—when run inside the repository—re-verifying every numerical table in `manuscript.md` and `technical_appendix.md` against the archived experiment JSON outputs.
- `REPLICATION_REPORT.json`: Machine-readable output summary generated by `verify_all.py`.

## Usage
```bash
python3 verify_all.py
```

Running `verify_all.py` completes in a few seconds on a single CPU core and exits with status `0` if and only if every mathematical, algorithmic, counterexample, and archived-table assertion passes.
